# naritopik.com (tạm thời)

Trang tạm cho tên miền chính `naritopik.com` trong lúc chưa có landing page.
Chỉ 3 đường dẫn dùng cho quảng cáo được chuyển sang trang học liệu `hoc.naritopik.com` (giữ cả `?…` và `#…`):

- `/ve-co/` → https://hoc.naritopik.com/ve-co/
- `/hoc-cung-co/` → https://hoc.naritopik.com/hoc-cung-co/
- `/thi-thu/` → https://hoc.naritopik.com/thi-thu/

Trang đầu (`index.html`) và `404.html` chỉ có logo + 3 nút trên. Học liệu nằm ở repo `nttn6889/narikoreanbox`.
Làm landing page thì thay `index.html`, giữ 3 thư mục chuyển hướng nếu link quảng cáo cũ còn dùng.
